# HUTA PLAY v2

واجهة عربية متجاوبة لمنصة أفلام ومسلسلات وأنمي.

## تشغيل محلي
- فك ضغط الملف.
- افتح `index.html` في متصفح حديث، أو استخدم استضافة Static.
- البحث والتصنيفات والمفضلة تعمل محلياً.
- لوحة الإدارة التجريبية تضيف عناصر إلى `localStorage` على نفس الجهاز.

## الفيديوهات
ثلاثة أمثلة تشغيل عامة من مشاريع Blender المفتوحة: Sintel وBig Buck Bunny وTears of Steel. راجع شروط ترخيص كل مشروع قبل إعادة النشر التجاري. باقي العناوين في المكتبة عناصر تجريبية بصور توضيحية، وليست روابط بث فعلية.

## النشر
ارفع محتويات المجلد إلى Netlify Drop أو مشروع Vercel Static. لا يوجد رابط عام تلقائي قبل تنفيذ النشر.

## قبل الإطلاق العام
- ربط Supabase Auth وDatabase.
- نقل صلاحيات الإدارة إلى Backend والتحقق من دور admin.
- عدم وضع مفاتيح service_role في المتصفح.
- إضافة محتوى مرخص فقط وروابط تشغيل مسموح بها.
- إعداد سياسة خصوصية وشروط استخدام.
